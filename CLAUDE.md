User's personal filters in `public/filters.txt`, host using Cloudflare pages on `filter.yanlincs.com`. GitHub CI workflow for deployment in `.github/workflows/deploy.yml`.

This collection of filters aims to cover either: 1. Toxic, good-for-nothing social sites, blocked entirely with network rules. Or, 2. Distracting elements from the remaining sites, blocked with cosmetic rules. Including recommendations, top and viral lists, comments, discussions, user lists, and the navigation entries leading to them. Leaving only the target information (e.g., subscription flow, search results, direct entry information).

The filters should be compatible with both ublock origin for Firefox and adguard for Safari.
